# NOIR

A luxury e-commerce storefront demo built with plain HTML, CSS and JavaScript. No frameworks, no build step.

**Live site:** https://oseim5226-coder.github.io/noir/

## Features

- Animated hero: light sweeps across the wordmark like it's coming through blinds
- Product grid with category filters
- Working shopping cart with quantity controls, subtotal and remove
- Cart saved between visits with localStorage
- Responsive, mobile-first layout
- Keyboard accessible, with reduced-motion support

## Tech

HTML5, CSS3 (custom properties, grid, flexbox), vanilla JavaScript, hosted on GitHub Pages.

## Run locally

Clone the repo and open index.html in a browser.

## Notes

This is a demo store. Nothing is for sale and no payments are processed.
